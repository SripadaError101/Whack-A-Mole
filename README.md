# Whack-a-Mole — Simple Web Game

Files:
- index.html
- style.css
- script.js

How to run:
1. Save the three files into the same folder.
2. Open `index.html` in your browser (no server required).
3. Click "Start" and click/tap the mole as it appears. Game lasts 30 seconds.
